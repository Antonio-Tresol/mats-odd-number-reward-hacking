Two things to know before filling these.

**The flag is `--paraphrase`, not `--treatment`.** There is no `--treatment`
option on `collect`; a command using it will fail.

```bash
uv run odd-number collect --model qwen/qwen3.8-27b --paraphrase p1 --n 40
```

**The agree arm is missing entirely wherever it reads 0, not merely short.**
`Q1.H1.E5` describes these runs as "both arms, n=40 each", so the tree currently
overstates what was collected for those cells. Filling qwen3.8's p1 to p4 on both
arms is 111 conflict plus 160 agree rollouts, roughly $1.20 at measured rates.

Filling them is cheap. Whether the wording question is worth answering is a
scoping call, but as it stands the wide intervals in that figure are a statement
about n, not about wording.

## New code, and the two traps it encodes

- `src/odd_number/branches.py` — resampling from truncation points, after Macar
  et al. (arXiv 2510.27484). `Resampler.sweep` is the entry point.
- `src/odd_number/chat_templates.py` — Qwen's chat template, rendered
  client-side.
- `odd-number branch --list --source <file>` prints branchable traces.
- 42 new tests across `tests/test_branches.py` and `tests/test_chat_templates.py`.

**Trap 1: the template is load-bearing and fails silently.** `/v1/completions`
applies no chat template, so it is rendered in `chat_templates.py`. Omitting the
reasoning-effort system block that `reasoning_effort|default('xhigh')` produces
still returns fluent, well-formed, correct-looking output at a ninth the
deliberation length: 976 median characters against 9,602. Nothing in the response
indicates this. If a second model is ever branched, transcribe its template from
`tokenizer_config.json` and validate at branch position zero before trusting any
curve.

**Trap 2: rate limits mimic a finding.** The first sweep lost 141 of 487 calls to
upstream 429s, all concentrated on the four branch points the thread pool
submitted first. In the data that is indistinguishable from those branch points
being special. `branches.py` now retries retriable statuses with jittered
backoff. Related: `collect` stops after 3 consecutive failures, so when Parasail
is throttling, a run appears to "finish" having collected almost nothing. The
agree arms needed spaced single-worker passes to land at all.

Also recorded: OpenRouter's completions endpoint silently drops `n`, returning
one choice for `n: 5` even under `require_parameters=True`. A hundred resamples
is a hundred requests.

## One number that is not settled

Branch position zero on the completions path gives 12/39 odd (30.8%) against the
chat path's 6/40 (15.0%) on the same pin and sampling. Fisher p = 0.11, intervals
overlap, point estimate doubles, and n≈40 per side cannot separate noise from a
real offset. Deliberation length and answer spread do match. Until this is
settled, read curves within the completions path and never against a chat-path
rate. Pushing position zero to n=120 would cost about $1.20 and would settle it.
